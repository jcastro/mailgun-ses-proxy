# 2.1.16: SES-Managed Header Compatibility

Recent Ghost newsletter requests can include `h:Message-Id`. That is valid for Mailgun, but SES does not allow callers to provide `Message-ID` as a custom header when using its Simple, Templated, or bulk sending APIs. Forwarding it caused SES to reject the request before accepting any recipients.

The proxy now excludes all headers in the [AWS-documented reserved list](https://docs.aws.amazon.com/ses/latest/dg/header-fields.html) from SES custom headers, case-insensitively. Previously handled address and subject headers continue to use their dedicated request fields. The additional filtered fields are `Content-Disposition`, `Content-Type`, `Date`, `Message-ID`, `MIME-Version`, and `Return-Path`.

`List-Unsubscribe`, `List-Unsubscribe-Post`, allowed custom headers, recipient variables, Ghost email IDs, tracking tags, and reply-to addresses are preserved. Both single and bulk send paths use the same filter.

## Update And Recovery

1. Back up the database and deployment configuration and retain the current image for rollback.
2. Update the proxy image to `ghcr.io/jcastro/mailgun-ses-proxy:v2.1.16` using the existing Compose update procedure. This release does not change the database schema.
3. Let the existing newsletter queue retry the original batch IDs. Do not create a second Ghost newsletter, reset sent-message records, or purge the queue to work around this error. Existing idempotency checks remain in effect.
4. If failed batches have already reached the configured dead-letter queue, inspect and redrive those original messages after verifying the fix and retaining their batch IDs.
5. Confirm SES acceptance, delivery events, Ghost statistics, and queue drainage. Historical error rows remain historical and are not evidence that the new attempts are failing.

This release makes no changes to suppression lists, subscription preferences, send-rate limits, credentials, or runtime dependencies. Existing operational and dependency limitations described in the 2.1.15 release notes still apply.
